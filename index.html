Sources & Methodology

This roadmap separates four kinds of statements, and never mixes them. It synthesizes the sources below in original wording — no article text, marketing copy or images are copied.

  • AWS requirement — facts from official AWS sources only (the AWS News Blog announcement and the Builder Center FAQ), stated as fact and cited inline.
  • Community synthesis — badge requirement paraphrases synthesized from individual-author Builder Center posts. Every badge's drawer lists exactly which sources were used, with what each contributed.
  • Recommended path — this tracker's own rules (phases, quest priorities, at-risk definition). Not AWS guidance, not community claims.
  • Your progress — your own logged data, stored only in this browser.
  • Anything AWS has not published is marked Verification needed instead of being guessed.
